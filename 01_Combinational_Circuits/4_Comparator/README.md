# 4-bit Comparator using Verilog HDL

## Overview
This project implements a 4-bit Comparator using Verilog HDL.

The comparator compares two 4-bit binary numbers and determines whether one number is greater than, less than, or equal to the other.

---

## Logic Conditions

| Condition | Output |
|---|---|
| A > B | Greater output HIGH |
| A < B | Less output HIGH |
| A = B | Equal output HIGH |
