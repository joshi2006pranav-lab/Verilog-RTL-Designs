# Parity Generator using Verilog HDL

## Overview
This project implements a Parity Generator using Verilog HDL.

A parity generator is used to generate a parity bit for error detection in digital communication systems.

---

## Truth Table

| Input Data | Parity Bit |
|---|---|
| Even number of 1's | 0 |
| Odd number of 1's | 1 |
