# 4-to-1 Multiplexer using Verilog HDL

## Overview
This project implements a 4-to-1 Multiplexer (MUX) using Verilog HDL.

A multiplexer selects one of the multiple input signals and forwards the selected input to a single output line based on the select inputs.

---

## Functionality

| Select Lines | Output |
|---|---|
| 00 | I0 |
| 01 | I1 |
| 10 | I2 |
| 11 | I3 |
