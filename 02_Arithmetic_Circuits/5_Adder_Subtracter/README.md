# Adder Subtracter using Verilog HDL

## Overview
This project implements an Adder-Subtracter circuit using Verilog HDL.

The circuit performs both binary addition and subtraction operations depending on the control input.

---

## Functionality

| Control Input | Operation |
|---|---|
| 0 | Addition |
| 1 | Subtraction |
