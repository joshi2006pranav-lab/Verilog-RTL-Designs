# Ripple Carry Adder using Verilog HDL

## Overview
This project implements a Ripple Carry Adder using Verilog HDL.

A Ripple Carry Adder performs multi-bit binary addition by connecting multiple Full Adders in series, where the carry output of one stage becomes the carry input of the next stage.

---

## Features

- Multi-bit binary addition
- Cascaded Full Adder architecture
- Carry propagation through stages
