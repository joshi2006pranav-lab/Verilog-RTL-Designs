# Carry Lookahead Adder using Verilog HDL

## Overview
This project implements a Carry Lookahead Adder (CLA) using Verilog HDL.

The Carry Lookahead Adder improves addition speed by generating carry signals in advance using generate and propagate logic instead of waiting for sequential carry propagation.

---

## Features

- Faster addition compared to Ripple Carry Adder
- Generate and Propagate logic implementation
- Reduced carry propagation delay
