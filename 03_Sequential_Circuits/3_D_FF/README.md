# D Flip-Flop using Verilog HDL

## Overview
This project implements a D (Data) Flip-Flop using Verilog HDL.

A D Flip-Flop stores a single bit of data and transfers the input value to the output on the triggering clock edge. It is widely used in registers and sequential logic circuits.

---

## Function Table

| Clock Edge | D | Q(next) |
|---|---|---|
| Triggered | 0 | 0 |
| Triggered | 1 | 1 |
