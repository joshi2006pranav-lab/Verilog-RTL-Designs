# Synchronous Loadable Counter using Verilog HDL

## Overview
This project implements a Synchronous Loadable Counter using Verilog HDL.

A Loadable Counter allows a predefined value to be loaded into the counter synchronously with the clock signal.

### Counter Operation

```text
Load Value  ==>  Counter Starts from Loaded State
```

It is commonly used in programmable timers, digital systems, and control applications.

---

## Features

- Synchronous operation
- Programmable initial count value
- Clock-driven counting
- Parallel data loading
