# T Flip-Flop using Verilog HDL

## Overview
This project implements a T (Toggle) Flip-Flop using Verilog HDL.

A T Flip-Flop changes its output state whenever the toggle input is HIGH during the triggering clock edge. It is commonly used in counters and frequency division circuits.

---

## Function Table

| T | Q(next) |
|---|---|
| 0 | No Change |
| 1 | Toggle |
