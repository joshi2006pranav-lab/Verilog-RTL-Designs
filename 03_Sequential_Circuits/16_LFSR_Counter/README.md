# LFSR Counter using Verilog HDL

## Overview
This project implements an LFSR (Linear Feedback Shift Register) Counter using Verilog HDL.

An LFSR Counter generates pseudo-random binary sequences using feedback logic and shift register stages.

### Data Flow

```text
Feedback Logic  ==>  Shift Register Stages  ==>  Pseudo-Random Sequence
```

LFSRs are widely used in cryptography, digital communication systems, random number generation, and test pattern generation.

---

## Features

- Pseudo-random sequence generation
- Feedback-based shift operation
- Efficient hardware implementation
- Sequential data generation
